# AI is under attack and the indicators of compromise are shocking.

Created on 2026-07-07 12:46

Published on ---

<div>

For years, security teams were trained to look for IPs, hashes, malware signatures, failed logins, suspicious processes, and unusual network traffic.

But AI systems are creating a new class of IOCs. The attack may not start with malware.

It may start with a hidden instruction inside a webpage. A prompt embedded in a document. A poisoned README file. A malicious tool description. A crafted email consumed by an AI assistant. A model suddenly leaking confidential context. An agent calling a tool it was never supposed to call. A spike in inference queries trying to reconstruct model behavior. A RAG pipeline retrieving poisoned knowledge. A chatbot exposing its system prompt. A copilot silently crossing the boundary between user intent and enterprise data.

This is the shift security leaders need to understand:

**AI compromise is not always infrastructure compromise. Sometimes it is intent compromise. Context compromise. Memory compromise. Tool compromise. Output compromise.**

The \#NextGen SOC will need visibility into AI behavior, not just endpoint behavior.

The real question is no longer: “Are we using AI securely?”

The real question is: **“Would we even know if our AI was being manipulated?”**
